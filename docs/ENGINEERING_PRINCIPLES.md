# Commercial Command Center

## Engineering Principles

### 1. Product over Scripts

We are building a product, not a collection of Python scripts.

Every component should be reusable, testable and documented.

---

### 2. Data is the Product

The dashboard is only a visualization.

The real product is the commercial data model.

---

### 3. Raw Data Never Changes

Raw tables are immutable.

Transformations happen in pipelines.

---

### 4. Small Iterations

Every sprint must produce working software.

No unfinished features.

---

### 5. One Responsibility

Each file should have one responsibility.

Avoid large files.

---

### 6. Business First

Every feature must answer a business question.

If it does not improve a business decision, it probably should not be built.

---

### 7. Simplicity Wins

Choose the simplest architecture that allows future growth.

Avoid unnecessary complexity.

---

### 8. Documentation is Code

Architecture decisions, roadmap and data model are part of the product.
